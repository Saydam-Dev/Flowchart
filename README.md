        <h1 color="Red">Flow Diagram - Flowchart</h2>
        <p>Flowchart is a program that lets you create diagrams for your algorithm logic. Visually appealing and very lightweight and runs on your linux mint machine due to its light but detailed design and now active on my portfolio as i used it for my personal works</p>
        <h3>Shape Definitions</h6>
        <div>
            <ul type="square">
                <li>Ovals to indicate a starting and ending point.</li>
                <li>Rectangles to indicate actions, tasks, operational steps.</li>
                <li>Diamonds to put a question line similiar to if statements goes 2 paths (y/n)</li>
                <li>Parallelograms to serve OUTPUT to user. Which can be both variable and text.</li>
                <li>Arrows to connect shapes to dictate the direction of algorithm executions.</li>
            </ul>
        </div>
